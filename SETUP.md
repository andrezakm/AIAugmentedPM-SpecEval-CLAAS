# Setup

Kurz, weil es kurz sein kann.

## Was du brauchst

- VS Code
- GitHub Copilot, Agent Mode aktiviert

Das war's. Kein Python, kein venv, kein pip, kein Streamlit, kein Server.

## Repo öffnen

1. Repository klonen oder als ZIP herunterladen
2. In VS Code öffnen
3. Copilot Chat öffnen, auf Agent Mode stellen

## Prototyp ansehen

Der Prototyp, den dein Agent baut, ist eine einzelne Datei: `app.html` (plus `data.js` daneben). Öffnen reicht:

- Im Finder/Explorer per Doppelklick — öffnet im Standardbrowser, oder
- In VS Code: Rechtsklick auf `app.html` → „Reveal in Finder" → Doppelklick, oder
- In VS Code: Rechtsklick auf `app.html` → „Open with Live Server" / „Show Preview", falls installiert

Kein Terminal-Befehl nötig. Wenn etwas nicht funktioniert, hilft die Browser-Konsole (Rechtsklick → „Untersuchen" → Tab „Console").
